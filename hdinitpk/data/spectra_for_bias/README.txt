Lensed CMB and CMB lensing spectra used by the bias calculation of
Figures 7 and 8. Each file holds five columns, in the order
TT, TE, EE, BB, kk, starting at ell = 2 and running to lmax = 24000.

    camb/lensed_lmax=24000_lens_potential_accuracy=<N>_camb_spectra.txt
        CAMB spectra over the accuracy grid N = 8, 10, 15, 20, 25, 30, 35, 40.

    class/lensed_lmax=24000_P_k_max_h_Mpc=<N>_class_spectra.txt
        CLASS spectra over the accuracy grid
        N = 50, 100, 200, ..., 1000.

    lensed_lmax=24000_true_universe_spectra.txt 
        The high-accuracy CAMB "true universe" spectra that the grids above
        are compared against.
